# Online Complaint Management System — Frontend

Responsive HTML, CSS and JavaScript frontend based on the uploaded project report.

## Run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox. No installation is required.

## Included UI
- Dashboard and complaint summary cards
- Recent complaints table
- Submit complaint form with category, title, description and location
- Rule-based priority calculation
- Unique complaint reference IDs
- Search and filter complaints by status
- Complaint details view
- Notifications and mark-as-read
- Responsive sidebar and mobile layout

## Demo limitation
This version stores demo data in the browser's `localStorage`; it is not connected to the Java/SQLite backend. The sample complaints are illustrative. For a fully integrated application, connect these screens to Java backend APIs or implement the interface using Java Swing.
